# PDF表格怎样保留证据结构

## 直接回答

不要只把表格转换成连续文本。应保存文档版本、页码、表格区域、单元格坐标、行列关系、表头路径、单位及合并关系，再生成供检索使用的文本视图。答案引用必须能定位原页与相关单元格；结构无法确认时，应保留原始证据并标记待复核，而非补齐猜测。

## 实际场景

采购人员询问不同年度的设备维护费。原表具有多层表头，单位写在表外，下一页还有续表。若切片只留下金额，检索即使命中数字，也可能混淆年份、币种与税前税后口径。证据包应一起返回行名、完整表头、单位、脚注和对应页面区域。

## 原理与取舍

可提取文字的 PDF 不一定保留逻辑表格；扫描页则需要另行设计 OCR 路径。提取无文字不能等同于页面无内容，应区分真实空白、扫描图片与解析失败，保留页状态以防静默丢页。

建议同时保存原页图像、结构化表格和检索文本。结构层负责单元格归属，文本层便于召回，原页用于复核。跨页合并应综合列位置、重复表头和续表标记，保存每段来源，不能仅凭列数相同拼接。识别投入越大，处理成本和复核成本也越高，应根据任务是否要求精确计算选择方案。

## 实现示例

以下为设计伪代码，未运行；描述目标数据流程，不是现有解析器接口。

```text
输入：授权文档及其固定版本
逐页登记页码、页面尺寸、旋转与提取状态
提取文本及位置；无文字页进入图像识别待办
识别表格候选，保存原始区域和单元格原文
建立行列、表头、单位、合并单元格关系
疑似跨页续表：校验结构；不确定则保留分段
按行组切片，附完整表头与证据定位
生成答案后核对每个数字、单位及引用单元格
证据缺失：拒绝给出确定数值，转人工复核
```

坐标需注明原点、尺寸与旋转变换，避免高亮落错位置。规范化数值应与原文分开保存，空单元格、零值和缺失值必须区分；计算结果还要记录操作与输入证据。

## 常见坑

按多个空格分列会误拆带空格的名称，也不能表达复杂合并关系。过滤页眉页脚可能删掉单位或说明。自动把首行当表头，会损坏无表头续表。只保存 Markdown 会弱化坐标和跨页来源；只引用文件名则无法验证具体结论。

## 验证清单

- 覆盖扫描页、混合页、旋转页与提取失败页。
- 人工核对多层表头、合并单元格、单位和脚注。
- 检查切片后每行是否仍有明确的列语义。
- 从答案引用反向打开原页，核对数字与位置。
- 对缺页、结构冲突和无答案问题验证拒答。
